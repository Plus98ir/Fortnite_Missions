# 🤖 ربات تلگرام ماموریت‌های فورتنایت (Save the World)

| [🇺🇸 English](README.md) | **🇮🇷 فارسی** |
| --- | --- |

رباتی برای **Fortnite: Save the World** که ماموریت‌های وی‌باکس، پاور ۱۶۰،
ونچر ۱۴۰، بهترین ماموریت‌های روز، جایزه هفتگی و تایمر سیزن‌ها را دنبال
می‌کند. به فارسی یا انگلیسی جواب می‌دهد، به صورت متن یا عکس آماده.

> [!IMPORTANT]
> **شرایط استفاده:** این ربات رایگان و متن‌باز است و **فقط برای استفاده شخصی**
> ساخته شده. **برای فروش نیست** و نباید فروخته یا تجاری استفاده شود.
> نام، آیکن‌ها و تصاویر فورتنایت **تحت انحصار و مالکیت Epic Games** هستند و
> این پروژه هیچ ارتباطی با Epic Games ندارد و مورد تأیید آن نیست.
> **مسئولیت نصب و استفاده کاملاً با خودتان است.**
> نصب‌کننده قبل از نصب، پذیرش این شرایط را از شما می‌پرسد.

## ⚙️ مرحله ۱ — دریافت توکن ربات

۱. تلگرام را باز کنید و **@BotFather** را جستجو کنید.<br>
۲. دستور `/newbot` را بفرستید.<br>
۳. یک نام نمایشی برای ربات انتخاب کنید.<br>
۴. یک نام کاربری یکتا که به `bot` یا `_bot` ختم شود انتخاب کنید (مثلاً `FortniteAlertsBot`).<br>
۵. توکن HTTP API را کپی کنید.

همچنین به **آیدی عددی** حساب ادمین نیاز دارید — به
[@userinfobot](https://t.me/userinfobot) پیام `/start` بدهید تا آن را بگیرید.

> ⚠️ **توکن را محرمانه نگه دارید.** هرگز آن را کامیت یا منتشر نکنید. اگر لو
> رفت، فوراً با `/revoke` در BotFather باطلش کنید.

## 🚀 مرحله ۲ — نصب

روی یک سرور دبیان یا اوبونتو، با کاربر روت:

</div>

```bash
bash <(curl -fsSL https://github.com/Plus98ir/Fortnite_Missions/releases/latest/download/install_fortnite_bot.sh)
```

<div dir="rtl">

نصب‌کننده اول **شرایط استفاده** را نشان می‌دهد و فقط اگر `yes` تایپ کنید ادامه
می‌دهد. بعد توکن، آیدی ادمین و (به‌صورت اختیاری) پروکسی را می‌پرسد و بقیه
کارها را خودش انجام می‌دهد: نصب پکیج‌ها، ساخت کاربر سرویس اختصاصی، محیط مجازی
پایتون، فایل پیکربندی، پک آرت و سرویس systemd سندباکس‌شده.

قبل از استارت سرویس، اتصال به تلگرام را تست می‌کند تا فوراً بفهمید مشکل از
**توکن** است یا از **شبکه**.

**برای آپدیت** دستور `fnbot update` را بزنید (یا دکمه **به‌روزرسانی** در پنل
ادمین). کانفیگ، کاربران و آرت‌های خودتان حفظ می‌شوند.

## 🖥 مدیریت ربات

دستور کمکی `fnbot` نصب می‌شود:

</div>

```bash
fnbot status        # آیا در حال اجراست؟
fnbot logs          # مشاهده زنده لاگ
fnbot errors        # فقط خطوط خطا
fnbot test          # تست اتصال تلگرام، مستقیم و با پروکسی
fnbot config        # ویرایش کانفیگ و ری‌استارت خودکار
fnbot update        # نصب آخرین نسخه، کانفیگ و کاربران حفظ می‌شوند
fnbot art [--force] # دانلود دوباره پک آرت
fnbot version
fnbot restart
fnbot uninstall     # حذف سرویس (کانفیگ و کاربران باقی می‌مانند)
```

## 🔧 پیکربندی

همه چیز در `/etc/fortnite_bot/bot.env` است (پرمیشن `0640`). با `fnbot config`
ویرایشش کنید؛ بعد از ذخیره، سرویس خودش ری‌استارت می‌شود.

| تنظیم | پیش‌فرض | توضیح |
| --- | --- | --- |
| `BOT_TOKEN` | — | توکن BotFather. |
| `ADMIN_CHAT_ID` | — | آیدی عددی ادمین. |
| `PROXY_URL` | خالی | مثل `socks5://user:pass@127.0.0.1:1080`. برای اتصال مستقیم خالی بگذارید. |
| `MAX_USERS` | `200` | سقف ظرفیت. اگر کاربر زیاد دارید بالا ببرید. |
| `DEFAULT_LANG` | `en` | `en` یا `fa`. |
| `IMAGE_MIN_CARDS` | `5` | حداقل ماموریت در هر عکس؛ ماموریت‌ها مساوی پخش می‌شوند (۵+۵، نه ۴+۱). |
| `IMAGE_MAX_CARDS` | `10` | سقف نرم تعداد ماموریت در هر عکس. |
| `TOP_PER_ZONE` | `5` | تعداد ماموریت هر زون در 🔥 ماموریت‌های برتر. |
| `ART_DIR` | `/opt/fortnite_bot/art` | پوشه آیکن‌ها و پس‌زمینه خودتان. |
| `ART_URL` | `art.zip` ریلیز | پک آرتی که موقع نصب/آپدیت دانلود می‌شود. `""` = خاموش. |
| `WEEKLY_URL2` | خالی | منبع دوم اختیاری برای جایزه هفتگی. |
| `DAILY_RESET_UTC` | `00:01` | زمان اعلان روزانه (۱ دقیقه بعد از ریست شاپ). |
| `WEEKLY_RESET_UTC` | `00:02` | زمان اعلان هفتگی (۲ دقیقه بعد از ریست). |
| `WEEKLY_RESET_WEEKDAY` | `3` | ۰ = دوشنبه … ۳ = پنجشنبه. |
| `SEASON_START_UTC` | — | شروع سیزن جاری، فرمت ISO. |
| `SEASON_END_UTC` | — | تاریخ پایان جایگزین، اگر دریافت زنده شکست بخورد. |
| `CACHE_SETTLE_MINUTES` | `20` | چند دقیقه بعد از ریست همچنان دنبال داده تازه بگردد. |
| `CACHE_SETTLE_TTL` | `300` | فاصله بررسی مجدد (ثانیه) در همان بازه. |
| `LOG_LEVEL` | `INFO` | برای لاگ کامل‌تر `DEBUG` بگذارید. |

> 📅 مقادیر `SEASON_START_UTC` و `SEASON_END_UTC` را هر سیزن یک بار به‌روز
> کنید. ربات تلاش می‌کند تاریخ پایان را زنده بخواند، ولی این‌ها پشتیبان هستند.

## 🎨 پک آرت

عکس‌ها از PNGهای داخل `ART_DIR` ساخته می‌شوند؛ هر چه نباشد را خود ربات
می‌کشد. ساختار: `background.png` در ریشه، آیکن ماموریت‌ها در `scenes/`، آیکن
جوایز در `rewards/`، جوایز هفتگی در `weekly/` و آیکن زون‌ها در `zone/`. اسم‌ها
انعطاف‌پذیرند (`V-Bucks.png` = `v_bucks.png` = `vbucks.png`)؛ لیست کامل در
توضیح بالای `ART_DIR` در `bot.env` است.

- `fnbot art --force` فایل `ART_URL` را دوباره دانلود و باز می‌کند.
- PNGهایی که خودتان دستی عوض کرده‌اید هیچ‌وقت بازنویسی نمی‌شوند.
- عکس‌هایی که پک قدیمی نصب کرده و در پک جدید نیستند پاک می‌شوند.

> آیکن‌های پیش‌فرض، آیتم‌های فورتنایت را نشان می‌دهند و متعلق به Epic Games
> هستند. فقط برای اینکه ربات در استفاده شخصی قابل استفاده باشد همراهش آمده‌اند.

## ⚙️ فیلترهای کاربر

هر کاربر **⚙️ فیلترهای من** (یا `/filters`) را باز می‌کند و زون‌ها و نوع جوایز
(V-Bucks، Survivor، Hero، Defender، Schematic، Trap، Evo Mat، Perk-Up، Gold، XP)
و کمیابی (Legendary، Epic) را انتخاب می‌کند؛ کمیابی و نوع باید هر دو روی یک
جایزه صدق کنند. این فیلترها فقط در **🔎 جستجوی جایزه** استفاده می‌شوند؛
لیست‌های معمولی و اعلان روزانه همیشه همه چیز را نشان می‌دهند.

## 👑 پنل مدیریت

دکمه **👑 Admin** را بزنید، یا مستقیم از دستورها استفاده کنید:

| دستور | کارکرد |
| --- | --- |
| `/stats` | تعداد کاربران، مشترکان، مسدودها و کاربران دارای فیلتر. |
| `/broadcast متن` | ارسال به همه مشترکان. اول پیش‌نمایش با دکمه تأیید/لغو نشان داده می‌شود. |
| `/cancel` | لغو پیام همگانی در انتظار. |
| `/ban آیدی` و `/unban آیدی` | مسدود یا آزاد کردن کاربر. کاربر مسدود بی‌صدا نادیده گرفته می‌شود. |
| `/banned` | لیست حساب‌های مسدود. |
| `/export` | دانلود فایل CSV از همه کاربران و تنظیماتشان. |
| `/import` | بازگرداندن کاربران — کافی است همان CSV یا یک `users.json` را برای ربات بفرستید. |
| `/refresh` | پاک کردن کش و دریافت مجدد در درخواست بعدی. |
| `/setweekly نوع` | ثبت دستی جایزه این هفته وقتی منبع اشتباه است (`weapon`، `hero`، `survivor`، `trap`، `defender`، `core`، `auto`). |
| `/update` | بررسی و نصب نسخه جدید. |

بازگردانی به صورت **ادغام** است: کاربران موجود به‌روز می‌شوند، جدیدها اضافه
می‌شوند و هیچ‌کس حذف نمی‌شود.

## 🗂 کش

ماموریت‌ها فقط سر ریست عوض می‌شوند، پس کش **تا ریست بعدی** معتبر است، نه یک
مدت ثابت:

| داده | معتبر تا | روی دیسک |
| --- | --- | --- |
| ماموریت‌ها، لیست‌های فیلترشده، عکس‌ها | ۰۰:۰۰ UTC بعدی | ✅ (ماموریت‌ها) |
| جایزه هفتگی | ریست هفتگی بعدی | ✅ |
| تاریخ پایان سیزن | روز بعد | در حافظه |

اولین درخواست روز داده را می‌گیرد و بقیه بلافاصله جواب می‌گیرند. اگر دریافت
شکست بخورد، به جای خطا همان داده قبلی نمایش داده می‌شود.

## 🔒 امنیت

- با کاربر سیستمی بدون دسترسی `fnbot` اجرا می‌شود، **نه روت**.
- توکن هیچ‌وقت وارد فایل‌های سورس نمی‌شود — فقط در فایل کانفیگ
  (`0640` و `root:fnbot`) قرار دارد.
- یوزر و پسورد پروکسی URL-encode می‌شوند و از همه لاگ‌ها حذف می‌شوند.
- یونیت systemd سندباکس شده است: `ProtectSystem=strict`، `NoNewPrivileges`،
  مجموعه capability خالی و فیلتر syscall.
- همه خروجی تلگرام HTML-escape می‌شود، پس نام ماموریت‌های دریافتی نمی‌توانند
  پیام را خراب کنند یا چیزی تزریق کنند.
- پک آرت امن باز می‌شود: فقط عکس، بدون خروج از مسیر، با محدودیت حجم.

## 🌐 پروکسی — اصلاً لازم است؟

فقط اگر سرورتان نتواند مستقیم به `api.telegram.org` برسد، که عملاً یعنی سرور
داخل ایران. سرورهای خارج باید `PROXY_URL` را خالی بگذارند.

پروکسی باید **از خود سرور** قابل دسترس باشد. `127.0.0.1` یعنی همان ماشین، نه
کامپیوتر شخصی شما. با این دستورها چک کنید:

</div>

```bash
ss -ltnp | grep <port>
fnbot test
```

## ❓ رفع اشکال

| نشانه | علت و راه‌حل |
| --- | --- |
| `httpx.ConnectError: All connection attempts failed` | تلگرام در دسترس نیست. `fnbot test` بزنید؛ اگر اتصال مستقیم کار کرد، `PROXY_URL` را خالی کنید. |
| بعد از آپدیت آیکن‌های قدیمی دیده می‌شوند | `fnbot art --force` را اجرا کنید. |
| تایمر بتل‌پس خطا می‌دهد | دریافت زنده تاریخ سیزن شکست خورده. `SEASON_END_UTC` را در کانفیگ تنظیم کنید. |
| جایزه هفتگی اشتباه است | منبع عقب است. با `/setweekly` جایزه درست را ثبت کنید. |
| سرویس در حلقه ری‌استارت می‌افتد | `fnbot errors` دلیل واقعی را در چند خط آخر نشان می‌دهد. |
