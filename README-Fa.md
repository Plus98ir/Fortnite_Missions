## 🇮🇷 راهنمای فارسی

### 📋 امکانات
* **هشدارهای لحظه‌ای وی‌باکس (V-Bucks):** به‌طور خودکار تشخیص داده و زمانی که ماموریت‌های روزانه دارای وی‌باکس باشند، اطلاع می‌دهد.
* **هشدارهای سوپرچارجر:** پیگیری فوری و دریافت اعلان زمانی که ماموریت‌های هفتگی یا ریست‌ها، سوپرچارجرهای Hero، Survivor، Weapon یا Trap را ارائه می‌دهند.
* **جوایز هفتگی:** هرگز آیتم‌های کمیاب پیشرفت هفتگی و آپگریدهای سطح بالا را از دست ندهید.
* **ردیاب ماموریت‌های PL 160:** بررسی آسان ماموریت‌های سطح بالای PL 160، مادیفایرهای منطقه (zone modifiers) و جوایز سوپرچارجر.
* **اسکریپت نصب تعاملی:** نصب سریع و خودکار تنها با یک دستور ترمینال، همراه با درخواست توکن ربات (Bot Token) شما.
 * **ارسال اعلان** ۱ دقیقه پس از به‌روزرسانی فروشگاه.
* **سریع و سبک:** ساخته شده برای حداقل مصرف منابع و زمان پاسخگویی فوری.

### ⚙️ مرحله ۱: دریافت توکن ربات تلگرام
قبل از نصب ربات، باید از طریق BotFather یک ربات تلگرام ایجاد کنید:
1. تلگرام را باز کرده و `@BotFather` را جستجو کنید.
2. یک چت باز کنید و دستور `/newbot` را ارسال کنید.
3. مراحل را دنبال کنید تا یک نام نمایشی (display name) برای ربات خود انتخاب کنید.
4. یک نام کاربری (username) منحصربه‌فرد انتخاب کنید که به `bot` یا `_bot` ختم شود (مثلاً `FortniteAlertsBot`).
5. توکن HTTP API ارائه شده توسط BotFather را کپی کنید.

 
> [!WARNING]
> توکن ربات خود را ایمن نگه دارید! آن را به صورت عمومی به اشتراک نگذارید یا در گیت‌هاب قرار ندهید.

### 🚀 مرحله ۲: نصب و پیکربندی
شما می‌توانید ربات را به راحتی با استفاده از اسکریپت نصب خودکار نصب و پیکربندی کنید:


```bash
bash <(curl -fsSL https://github.com/Plus98ir/Fortnite_Missions/releases/latest/download/install.sh)
```



**توجه: پیکربندی برای سرورهای ایران**

اگر ربات را روی سرور ایران نصب می‌کنید، باید یک پروکسی تنظیم کنید. لطفاً مراحل زیر را دنبال کنید:

**۱. تنظیم آدرس پروکسی**
فایل ربات را با استفاده از ویرایشگر متن خود باز کنید:



```bash
nano /root/fortnite_bot/vbucks_bot.py
```



متغیر `PROXY_URL` را پیدا کنید، مشخصات پروکسی خود را وارد کرده و با حذف علامت `#` خط را از حالت کامنت خارج کنید:


```python
PROXY_URL = "socks5://username:password@127.0.0.1:port"
```


**۲. فعال‌سازی پروکسی در برنامه**
به پایین و بخش `if __name__ == '__main__':` بروید و **دو** خط زیر را از حالت کامنت خارج کنید تا تنظیمات پروکسی اعمال شود:



```python
# Uncomment if proxy is needed:
t_request = HTTPXRequest(proxy=PROXY_URL)
application = ApplicationBuilder().token(TOKEN).request(t_request).get_updates_request(t_request).build()
```



**۳. ری‌استارت کردن سرویس vbucksbot**
```bash
systemctl restart vbucksbot.service
```
* **ضمنا**
* اگر سرور ندارید یا حوصله نصب و راه‌اندازی آن را ندارید، می‌توانید از ربات من استفاده کنید. فقط در جریان باشید که نمی‌دانم این ربات تا چه زمانی فعال خواهد ماند:




```python
  @plus98vbucks_bot
```


* ظرفیت پیش‌فرض برای ارسال اعلان‌های ماموریت روی ۲۰۰ کاربر تنظیم شده است.
* برای تغییر این محدودیت در سرور خود، اسکریپت را با استفاده از دستور **(nano /root/fortnite_bot/vbucks_bot.py)** ویرایش کنید، 
* متغیر **MAX_USERS = 200** را پیدا کرده و آن را به عدد دلخواه خود تغییر دهید.
