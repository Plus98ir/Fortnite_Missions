## 🇮🇷 راهنمای فارسی

### 📋 ویژگی‌ها و امکانات
* **هشدار لحظه‌ای وی‌باکس:** تشخیص و ارسال خودکار نوتیفیکیشن هنگام قرار گرفتن وی‌باکس در مأموریت‌های روزانه.
* **هشدار سوپرشارژرها:** ردیابی و دریافت هشدار آنی به محض اینکه مأموریت‌های هفتگی یا ریست‌های ویژه، سوپرشارژر هیرو، بازمانده (Survivor)، سلاح یا تپ را ارائه دهند.
* **جوایز باارزش:** هرگز آیتم‌های کمیاب پیشرفت هفتگی و آپدیت‌های سطح بالا را از دست ندهید.
* **ردیاب مأموریت‌های 160 پی‌ال:** بررسی آسان مأموریت‌های سطح بالا، مودیفایرها و جوایز سوپرشارژر.
* **اسکریپت نصب تعاملی:** نصب خودکار و سریع با یک دستور در ترمینال همراه با دریافت توکن ربات.
* **سبک و سریع:** بهینه شده برای مصرف حداقل منابع و پاسخگویی آنی.

### ⚙️ گام اول: دریافت توکن ربات تلگرام
قبل از نصب، باید یک ربات تلگرام از طریق BotFather بسازید:
1. در تلگرام عبارت `@BotFather` را جستجو کنید.
2. چت را شروع کرده و این دستور را بفرستید: `/newbot`
3. طبق راهنما یک نام نمایشی برای ربات انتخاب کنید.
4. یک نام کاربری یکتا که به `bot` یا `_bot` ختم شود وارد کنید (مثلاً: `FortniteAlertsBot`).
5. توکن HTTP API دریافت شده از BotFather را کپی کنید.

> [!WARNING]
> توکن ربات خود را امن نگه دارید! آن را به صورت عمومی منتشر نکنید یا روی گیت‌هاب قرار ندهید.
