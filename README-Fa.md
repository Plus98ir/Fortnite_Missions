<h2>🇮🇷 راهنمای فارسی</h2>

<h3>📋 امکانات</h3>

<ul>
<li><b>هشدارهای لحظه‌ای وی‌باکس (V-Bucks):</b> به‌طور خودکار تشخیص داده و زمانی که ماموریت‌های روزانه دارای وی‌باکس باشند، اطلاع می‌دهد.</li>
<li><b>هشدارهای سوپرچارجر:</b> پیگیری فوری و دریافت اعلان زمانی که ماموریت‌های هفتگی یا ریست‌ها، سوپرچارجرهای Hero، Survivor، Weapon یا Trap را ارائه می‌دهند.</li>
<li><b>جوایز هفتگی:</b> هرگز آیتم‌های کمیاب پیشرفت هفتگی و آپگریدهای سطح بالا را از دست ندهید.</li>
<li><b>ردیاب ماموریت‌های PL 160:</b> بررسی آسان ماموریت‌های سطح بالای PL 160، مادیفایرهای منطقه (Zone Modifiers) و جوایز سوپرچارجر.</li>
<li><b>اسکریپت نصب تعاملی:</b> نصب سریع و خودکار تنها با یک دستور ترمینال، همراه با درخواست توکن ربات (Bot Token) شما.</li>
<li><b>ارسال اعلان:</b> یک دقیقه پس از به‌روزرسانی فروشگاه.</li>
<li><b>سریع و سبک:</b> ساخته شده برای حداقل مصرف منابع و زمان پاسخگویی فوری.</li>
</ul>


<h3>⚙️ مرحله ۱: دریافت توکن ربات تلگرام</h3>

قبل از نصب ربات، باید از طریق BotFather یک ربات تلگرام ایجاد کنید:

<ol>
<li>تلگرام را باز کرده و <code>@BotFather</code> را جستجو کنید.</li>
<li>یک چت باز کنید و دستور <code>/newbot</code> را ارسال کنید.</li>
<li>مراحل را دنبال کنید تا یک نام نمایشی (Display Name) برای ربات خود انتخاب کنید.</li>
<li>یک نام کاربری (Username) منحصربه‌فرد انتخاب کنید که به <code>bot</code> یا <code>_bot</code> ختم شود.</li>
<li>توکن HTTP API ارائه شده توسط BotFather را کپی کنید.</li>
</ol>

<div>

⚠️ <b>هشدار:</b><br>
توکن ربات خود را ایمن نگه دارید! آن را به صورت عمومی به اشتراک نگذارید یا در گیت‌هاب قرار ندهید.

</div>

<h3>⚠️ توجه: پیکربندی برای سرورهای ایران</h3>

اگر ربات را روی سرور ایران نصب می‌کنید، باید یک پروکسی تنظیم کنید. لطفاً مراحل زیر را دنبال کنید:

<h4>۱. تنظیم آدرس پروکسی</h4>

فایل ربات را با استفاده از ویرایشگر متن خود باز کنید:

</div>

```bash
nano /root/fortnite_bot/vbucks_bot.py
```

<div dir="rtl" align="right">

متغیر <code>PROXY_URL</code> را پیدا کنید، مشخصات پروکسی خود را وارد کرده و با حذف علامت <code>#</code> خط را از حالت کامنت خارج کنید:

</div>

```python
PROXY_URL = "socks5://username:password@127.0.0.1:port"
```

<div dir="rtl" align="right">

<h4>۲. فعال‌سازی پروکسی در برنامه</h4>

به پایین و بخش <code>if **name** == '**main**':</code> بروید و دو خط زیر را از حالت کامنت خارج کنید:

</div>

```python
# Uncomment if proxy is needed:
t_request = HTTPXRequest(proxy=PROXY_URL)
application = ApplicationBuilder().token(TOKEN).request(t_request).get_updates_request(t_request).build()
```

<div dir="rtl" align="right">

<h4>۳. ری‌استارت کردن سرویس vbucksbot</h4>

</div>

```bash
systemctl restart vbucksbot.service
