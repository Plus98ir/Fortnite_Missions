## 🇮🇷 راهنمای فارسی

### 📋 امکانات
* **هشدارهای لحظه‌ای وی‌باکس (V-Bucks):** به‌طور خودکار تشخیص داده و زمانی که ماموریت‌های روزانه دارای وی‌باکس باشند، اطلاع می‌دهد.
* **هشدارهای سوپرچارجر:** پیگیری فوری و دریافت اعلان زمانی که ماموریت‌های هفتگی یا ریست‌ها، سوپرچارجرهای Hero، Survivor، Weapon یا Trap را ارائه می‌دهند.
* **جوایز هفتگی:** هرگز آیتم‌های کمیاب پیشرفت هفتگی و آپگریدهای سطح بالا را از دست ندهید.
* **ردیاب ماموریت‌های PL 160:** بررسی آسان ماموریت‌های سطح بالای PL 160، مادیفایرهای منطقه (zone modifiers) و جوایز سوپرچارجر.
* **اسکریپت نصب تعاملی:** نصب سریع و خودکار تنها با یک دستور ترمینال، همراه با درخواست توکن ربات (Bot Token) شما.
* **ارسال اعلان:** ۱ دقیقه پس از به‌روزرسانی فروشگاه.
* **سریع و سبک:** ساخته شده برای حداقل مصرف منابع و زمان پاسخگویی فوری.

### ⚙️ مرحله ۱: دریافت توکن ربات تلگرام
قبل از نصب ربات، باید از طریق BotFather یک ربات تلگرام ایجاد کنید:
1. تلگرام را باز کرده و `@BotFather` را جستجو کنید.
2. یک چت باز کنید و دستور `/newbot` را ارسال کنید.
3. مراحل را دنبال کنید تا یک نام نمایشی (display name) برای ربات خود انتخاب کنید.
4. یک نام کاربری (username) منحصربه‌فرد انتخاب کنید که به `bot` یا `_bot` ختم شود (مثلاً `FortniteAlertsBot`).
5. توکن HTTP API ارائه شده توسط BotFather را کپی کنید.

> [!WARNING]
> توکن ربات خود را ایمن نگه دارید! آن را به صورت عمومی به اشتراک نگذارید یا در گیت‌هاب قرار ندهید.
