## 📌 راهنمای فارسی

### امکانات:
* **تشخیص و اطلاع‌رسانی V-Bucks:** به‌طور خودکار مأموریت‌های روزانه دارای V-Bucks را تشخیص داده و اطلاع‌رسانی می‌کند.
* **مأموریت‌های Supercharger:** هشدار فوری زمانی که مأموریت‌ها یا ریست‌ها مأموریت‌های Hero, Survivor, Weapon یا Trap Supercharger را ارائه می‌دهند.
* **بررسی هماهنگی تجهیزات هفتگی:** پیگیری هفتگی و خودکار هماهنگی تجهیزات هفتگی و آیکون‌های سطح بالا را از دست ندهید.
* **مانیتورینگ منطقه 160PL:** بررسی آسان مأموریت‌های سطح بالای 160PL مأموریت‌های Zone modifiers و حرارت سورپارجر (zone modifiers).
* **اسکریپت نصب:** نصب سریع و خودکار تنها با یک دستور ترمینال - همراه با درخواست توکن ربات (Bot Token) و تنظیمات پروکسی همراه با درخواست خودکار ربات.
* **ارسال alerts:** ۱ دقیقه پس از به‌روزرسانی فروشگاه.
* **سرعتی و سبک:** ساخته شده برای حداقل مصرف منابع و زمان پاسخگویی فوری.

---

### مرحله ۱: دریافت توکن ربات تلگرام

1. یک ربات تلگرام ایجاد کنید. به **BotFather** در تلگرام بروید.
2. با دستور `/newbot` یک ربات جدید بسازید و نام و نام کاربری (`username`) را انتخاب کنید (مثلاً `FortniteAlertsBot`).
3. توکن HTTP API را کپی کنید.

---

### مرحله ۲: نصب و راه‌آفرینی

با یک دستور ساده می‌توانید ربات را روی سرور ایران نصب و راه‌اندازی کنید:

```bash
bash <(curl -fsSL [https://github.com/Plus98ir/Fortnite_Missions/releases/latest/download/install.sh](https://github.com/Plus98ir/Fortnite_Missions/releases/latest/download/install.sh))
```

**توجه: پیکربندی برای سرورهای ایران**

اگر ربات را روی سرور ایران نصب می‌کنید، باید یک پروکسی تنظیم کنید. لطفاً مراحل زیر را دنبال کنید:

**۱. تنظیم آدرس پروکسی**
فایل ربات را با استفاده از ویرایشگر متن خود باز کنید:
```bash
nano /root/fortnite_bot/vbucks_bot.py
```
متغیر `PROXY_URL` را پیدا کنید، مشخصات پروکسی خود را وارد کرده و با حذف علامت `#` خط را از حالت کامنت خارج کنید:
```python
PROXY_URL = "socks5://username:password@127.0.0.1:port"
```

**۲. فعال‌سازی پروکسی در برنامه**
به پایین و بخش `if __name__ == '__main__':` بروید و **دو** خط زیر را از حالت کامنت خارج کنید تا تنظیمات پروکسی اعمال شود:
```python
# Uncomment if proxy is needed:
t_request = HTTPXRequest(proxy=PROXY_URL)
application = ApplicationBuilder().token(TOKEN).request(t_request).get_updates_request(t_request).build()
```

**۳. ری‌استارت کردن سرویس vbucksbot**
```bash
systemctl restart vbucksbot.service
```
* **ضمنا**
* اگر سرور ندارید یا حوصله نصب و راه‌اندازی آن را ندارید، می‌توانید از ربات من استفاده کنید. فقط در جریان باشید که نمی‌دانم این ربات تا چه زمانی فعال خواهد ماند:

```python
  @plus98vbucks_bot
```
* ظرفیت پیش‌فرض برای ارسال اعلان‌های ماموریت روی ۲۰۰ کاربر تنظیم شده است.
* برای تغییر این محدودیت در سرور خود، اسکریپت را با استفاده از دستور **(nano /root/fortnite_bot/vbucks_bot.py)** ویرایش کنید، 
* متغیر **MAX_USERS = 200** را پیدا کرده و آن را به عدد دلخواه خود تغییر دهید.
