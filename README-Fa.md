هشدار لحظه‌ای وی‌باکس: تشخیص و ارسال خودکار نوتیفیکیشن هنگام قرار گرفتن وی‌باکس در مأموریت‌های روزانه.

اعلان سوپرشارژرها و جوایز ویژه: ردیابی و دریافت هشدار آنی به محض اینکه مأموریت‌ها یا ریست‌های ویژه، سوپرشارژر هیرو، بازمانده (Survivor)، سلاح یا تپ را ارائه دهند.

جوایز باارزش: هرگز آیتم‌های کمیاب پیشرفت هفتگی و آپدیت‌های سطح بالا را از دست ندهید.

ردیاب مأموریت‌های 160 پی‌ال: بررسی آسان مأموریت‌های سطح بالا، مودیفایرها و جوایز.

اسکریپت نصب تعاملی: نصب خودکار و سریع با یک دستور در ترمینال و دریافت تعاملی توکن ربات.

سبک و سریع: بهینه شده برای مصرف حداقل منابع و پاسخگویی آنی.

⚙️ گام اول: دریافت توکن ربات تلگرام
قبل از نصب، باید یک ربات تلگرام از طریق BotFather بسازید:

در تلگرام عبارت @BotFather را جستجو کنید.

چت را شروع کرده و این دستور را بفرستید:

Plaintext
/newbot
طبق راهنما یک نام نمایشی برای ربات انتخاب کنید.

یک نام کاربری یکتا که به bot یا _bot ختم شود وارد کنید (مثلاً: FortniteAlertsBot).

توکن (HTTP API Token) دریافت شده از BotFather را کپی کنید.

[!WARNING]
توکن ربات خود را امن نگه دارید! آن را به صورت عمومی منتشر نکنید یا روی گیت‌هاب قرار ندهید.

🚀 گام دوم: نصب و راه‌اندازی
می‌توانید به راحتی با استفاده از اسکریپت نصب خودکار، پروژه را راه‌اندازی کنید:

Bash
bash <(curl -s https://raw.githubusercontent.com/Sadiqira/Fortnite_Missions/refs/heads/main/setup.sh)
در طول فرآیند نصب، اسکریپت به صورت تعاملی از شما می‌خواهد توکن ربات تلگرام خود را وارد کنید:

Plaintext
👉 لطفاً توکن ربات تلگرام خود را وارد کنید: [توکن خود را اینجا پیست کنید]
پس از وارد کردن، تنظیمات به صورت امن ذخیره شده و ربات شما آماده اجراست!
