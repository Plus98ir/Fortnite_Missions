  • جوایز هفتگی: هرگز آیتم‌های کمیاب پیشرفت هفتگی و آپگریدهای سطح بالا را از دست ندهید

  • اسکریپت نصب تعاملی: نصب سریع و خودکار تنها با یک دستور ترمینال
  • ارسال اعلان ۱ دقیقه پس از به‌روزرسانی فروشگاه
  • سریع و سبک: ساخته شده برای حداقل مصرف منابع و زمان پاسخگویی فوری

⚙️ مرحله ۱: دریافت توکن ربات تلگرام

قبل از نصب ربات، باید از طریق BotFather یک ربات تلگرام ایجاد کنید:

  1. تلگرام را باز کرده و @BotFather را جستجو کنید
  2. یک چت باز کنید و دستور /newbot را ارسال کنید
  3. مراحل را دنبال کنید تا یک نام نمایشی برای ربات خود انتخاب کنید
  4. یک نام کاربری منحصربه‌فرد انتخاب کنید که به bot یا _bot ختم شود (مثلاً FortniteAlertsBot)
  5. توکن HTTP API ارائه شده توسط BotFather را کپی کنید
⚠️ هشدار: توکن ربات خود را ایمن نگه دارید! آن را به صورت عمومی به اشتراک نگذارید یا در گیت‌هاب قرار ندهید

توجه: پیکربندی برای سرورهای ایران

اگر ربات را روی سرور ایران نصب می‌کنید، باید یک پروکسی تنظیم کنید. لطفاً مراحل زیر را دنبال کنید:

۱. تنظیم آدرس پروکسی

فایل ربات را باز کنید:

nano /root/fortnite_bot/vbucks_bot.py

متغیر PROXY_URL را پیدا کنید و خط را از حالت کامنت خارج کنید:

PROXY_URL = "socks5://username:password@127.0.0.1:port"
۲. فعال‌سازی پروکسی در برنامه

به بخش if __name__ == '__main__': بروید و دو خط زیر را از حالت کامنت خارج کنید:

# Uncomment if proxy is needed:
t_request = HTTPXRequest(proxy=PROXY_URL)
application = ApplicationBuilder().token(TOKEN).request(t_request).get_updates_request(t_request).build()
۳. ری‌استارت کردن سرویس
systemctl restart vbucksbot.service
